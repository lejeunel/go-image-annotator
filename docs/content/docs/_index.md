A lightweight and open source web app to manage, store, and annotate images.
It aims to be a solution "without moving parts", i.e. bundles
authentication, group and role-based access control, as well as
a portable relational database driver.

This application is well suited for small/medium sized teams
working on computer vision projects, where annotating images 
allow to train and evaluate Machine Learning models.

## Notable features

- Annotate images with image-wise labels, bounding-boxes or polygons.
- Assign custom meta-data
- Filter and sort images using a simple query language.
- Automate tasks through an extensive API using an SDK written in Python.
- Create annotation profiles to restrict pre-defined subsets of labels.
- Authenticate users with simple password or use an OAuth provider.
- Leverage group and role-based access control for safer collaboration between multiple users.
- Track your contributions by versioning your annotations.
